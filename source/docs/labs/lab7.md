# Лабораторная работа. Классификация тональности твитов

## Цель работы

Цель работы — изучить базовые методы обработки текстовых данных и построить модель классификации тональности твитов.

## Описание данных

В работе использовались два набора твитов: положительные и отрицательные. Для каждого текста был добавлен целевой признак `label`, принимающий значения `positive` и `negative`.

Данные были объединены в один датафрейм, после чего разделены на обучающую и тестовую выборки.

## Выполненные этапы

В ходе работы были выполнены следующие шаги:

- загрузка положительных и отрицательных твитов;
- объединение данных в один датафрейм;
- разделение данных на train/test;
- векторизация текста с помощью CountVectorizer;
- обучение LogisticRegression;
- проверка качества модели на тестовой выборке;
- сравнение униграмм, биграмм, триграмм и пентаграмм;
- использование TF-IDF-векторизации;
- проверка токенизации с помощью `word_tokenize`;
- анализ влияния пунктуации;
- проверка символьных n-грамм.

## Самостоятельная работа

В самостоятельной части были проверены несколько моделей классификации:

- LogisticRegression;
- MultinomialNB;
- LinearSVC;
- XGBClassifier.

Для признаков использовалась TF-IDF-векторизация. Основной метрикой для сравнения был выбран `weighted f1-score`, так как он учитывает качество классификации по обоим классам.

Лучший результат среди моделей показала `LogisticRegression`:

- accuracy: `0.756317`
- weighted f1-score: `0.756161`

Для сравнения:

| Модель | Accuracy | Weighted F1 |
|---|---:|---:|
| LogisticRegression | 0.756317 | 0.756161 |
| LinearSVC | 0.751656 | 0.751656 |
| MultinomialNB | 0.748487 | 0.748487 |
| XGBClassifier | 0.725291 | 0.725291 |

## Сравнение TF-IDF n-грамм

Также были проверены разные варианты TF-IDF-векторизации:

| Вариант | Weighted F1 |
|---|---:|
| Униграммы | 0.754947 |
| Биграммы | 0.691936 |
| Триграммы | 0.575849 |
| Пентаграммы | 0.401079 |

Лучше всего сработали униграммы. Биграммы, триграммы и пентаграммы показали более слабый результат, потому что длинные n-граммы встречаются реже и хуже обобщаются на тестовую выборку.

## Вывод

В результате работы была построена модель классификации тональности твитов. Лучшее качество среди проверенных моделей показала LogisticRegression с TF-IDF-признаками.

Также было видно, что пунктуация в этом датасете сильно влияет на классификацию: символ `)` оказался связан с положительным классом. Это показывает, что при работе с текстовыми данными важно внимательно анализировать признаки, а не только применять стандартные методы очистки.
